## 📖 What Is dsh-lark-bot?

dsh-lark-bot is a friendly bridge that connects **DeepSeek Harness (dsh)** to your **Feishu (Lark)** messaging app. Think of it as a helpful messenger that lets you chat with the powerful DeepSeek AI directly from your Feishu workspace.

**In simple terms:**  
- You type a message in Feishu  
- dsh-lark-bot sends it to DeepSeek Harness  
- DeepSeek's answer comes back to you in Feishu  

No coding, no complex setup – just connect and chat.
