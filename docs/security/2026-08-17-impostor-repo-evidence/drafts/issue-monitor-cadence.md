# 标题

`ops(security): 假冒仓库与仿冒包监控常态化（运行方式决策）`

# 正文

## 背景

`scripts/monitor-impostor-repo.mjs`（`pnpm security:monitor`）已就绪并建立基线（2026-08-17）。
需要确定常态化运行方式，确保假冒仓库 Releases 出现附件时第一时间告警并固证。

## 方案选项

1. **本机 cron**：每周一次，变化时退出码 2 → 输出日志 / 邮件告警
2. **GitHub Actions schedule（每周）**：注意——在官方仓库跑监控会留下公开执行痕迹，
   与“不打草惊蛇”策略存在冲突，需权衡
3. **维护者手动每周运行**（最简单，依赖纪律）

## 待决策

- 运行方式（1 / 2 / 3）
- 告警接收渠道（邮箱 / 飞书 / 仅日志）
- 是否纳入 AGENTS.md 例行检查清单

## 验收

- 每周至少成功运行一次；假冒仓库出现 Release 附件后 24 小时内完成人工确认与固证
- 基线状态文件 `~/.dsh-lark/security-monitor-state.json` 持续更新
