dsh-lark-bot

把 DeepSeek Harness（dsh）装进飞书 / Lark，扫码即用。在手机飞书里指挥本机 coding agent：发消息就收流式卡片与工具调用过程；bot 卡片按每位读者语言显示中文 / English，把跨语言团队的对话、任务、卡片和项目工作区收进同一个协作流。

DeepSeek Harness 怎么连接飞书

  1. 安装 Node.js ≥ 22，并安装 DeepSeek Harness（dsh）与配置 DEEPSEEK_API_KEY。
  2. 一条命令安装桥接插件：
    npx dsh-lark-bot@latest setup --profile dsh-lark
  3. 启动并用飞书 App 扫码：
    dsh --profile dsh-lark
    终端打印二维码，用飞书 / Lark App 扫码创建或选择 PersonalAgent 应用，绑定即完成。
  4. 私聊直接发消息；群聊 / 话题里 @bot。
⚠️ 官方渠道声明：唯一官方仓库是 github.com/PlutoKeating/dsh-lark-bot；唯一官方 npm 包是 dsh-lark-bot / dsh-feishu-bot（维护者 plutokeating）。本项目从不提供 .exe 或“下载即运行”的安装包，任何此类第三方分发均为假冒 / 恶意来源。

核心能力（十二项组合全网独有）

  • 安全网守护：dsh 进程崩溃后机器人仍会在飞书回复你，可进入仅核心安全模式并在对话里发控制信号把它重启——唯一“出故障时用户不会失联”的项目。
  • 多角色 Agent：/role 切换或指派 PM / 开发 / 文档等角色，每个角色有持久化的人设、模型偏好与规则。一个机器人，一整个团队。
  • 多机器人可信交接：每个实例有独立身份、服务、凭据和上下文；同群只接受登记 peer 的真实 @ 交接，并以共享计数上限阻止无限互聊。
  • 并行多任务：同一群里同时跑多个任务，各自会话隔离，不用排队。
  • 崩溃后任务可对账：消息先持久落盘再入队，重启恢复排队项；中断任务可用 /jobs 查看 checkpoint 并显式重试。
  • 会话归档与清理：/archive、/retention 管理旧任务与自动保留策略，会话列表不会越积越多。
  • 跨会话主动通知 + @人：Agent 在 A 群跑完任务，可主动发消息到 B 群或私聊并 @ 你。
  • dsh Web 可视化设置：在官方 Settings → Plugins 页面查看和修改应用、workspace、模型、并行数与提醒；密钥只写不回显，并内置诊断快捷入口。
  • 对话内管理模型和密钥：/model、/providers、/key 直接在聊天里查看、切换供应商、热更新密钥，全程不离开飞书。
  • 快速 / 平衡 / 深度执行模式：发送 /mode 用双语卡片按会话选择任务强度，简单问答更快、复杂重构更谨慎；下一轮生效且不打断当前任务。
  • 关键任务计划门禁：先发送完整计划，再由卡片批准执行或带意见继续规划，原任务自动续跑。
  • 飞书内自更新：管理员发送 /upgrade 检查 npm 官方包，确认卡后由 Guardian 后台更新、验证并重载；/new 仅在有更新时发一条短提醒。

常见问题

DeepSeek Harness 怎么接入飞书？

见上方安装步骤：一条命令安装 + 扫码绑定，全程不需要公网服务器、域名或内网穿透。

需要公网 IP 或服务器吗？

不需要。飞书通道使用 WebSocket 长连接（出站），NAT 后面也能用，代码始终只在本机运行，飞书只传输消息。

dsh 崩溃了怎么办？

默认安装的安全网守护会接管飞书通道，发 /safemode 进入仅核心安全模式自愈，/safemode exit 恢复完整 profile。

和其他飞书插件有什么区别？

功能最全：安全网守护、多角色、多机器人可信交接、并行任务、持久任务对账、会话归档、跨会话通知、dsh Web 可视化设置、对话内模型 / 密钥管理、执行模式、计划门禁与飞书内自更新十二项组合为一，标准 dsh profile bundle 一条命令安装。

能用手机远程用吗？

可以。飞书手机 App 扫码绑定后，随时给机器人发消息指挥本机 agent，任务完成还会主动推送并 @ 你。

怎么确认下载的是正版？

只从 github.com/PlutoKeating/dsh-lark-bot 与 npm（dsh-lark-bot / dsh-feishu-bot）获取；凡提供 exe 的渠道均为假冒。
