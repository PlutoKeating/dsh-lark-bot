# v0.19.2 — Reliable compatibility and release gates

- Repairs the real dsh compatibility probe after the scope-policy preflight protocol changed, with separate accounting for policy checks, silent low-risk allows, and true one-shot approvals.
- Adds a fast contract regression test that compares the probe fixture with the production approval handler, preventing callback response drift from turning into long model loops.
- Requires the full SDK/ACP compatibility probe before GitHub Release uploads or npm publication, so a compatibility-red build cannot publish successfully.
- Eliminates a portable-supervisor shutdown race that could lose a child exit event while status persistence was pending, and locks the ordering with a deterministic concurrency test.

Upgrade and reload the managed profile:

```bash
npx dsh-lark-bot@latest upgrade --profile dsh-lark --yes --restart
```
