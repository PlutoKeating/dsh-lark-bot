## Highlights / 本版亮点

- **彻底修复交互卡片（issue #47 第三次修复）**：飞书卡片 schema 2.0 已废弃 `action`
  容器（Open Platform 以 sub-code 200861 拒绝整张卡片），导致管理卡片、向导卡片、
  审批卡、问答卡里的按钮全部无法渲染。本版把所有按钮改为直接放在 `body.elements`
  （横向成组用 `column_set` 自动宽列），文本/选择输入改用 `form` 容器包裹并绑定
  `form_action_type: "submit"` 提交按钮，回调经 `action.form_value` 取输入值，
  `/providers` 管理中心与 BotFather 式多轮向导在飞书里真正可见可点。
- **向导输入卡支持必填校验**：必填步骤的输入框带 `required`，客户端阻止空提交；
  可选步骤（如显示名称、凭据引用名）保持可跳过。

**安装 / 升级 · Install & upgrade**：

```bash
npx dsh-lark-bot@latest setup --profile dsh-lark
npx dsh-lark-bot@latest upgrade --profile dsh-lark --yes
```
