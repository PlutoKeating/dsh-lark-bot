## Highlights / 本版亮点

- **官方 dsh Web 可视化设置（issue #36）**：在 **Settings → Plugins** 直接配置飞书/Lark
  区域、App ID、只写 App Secret、workspace、模型、并行数、adapter 与提醒默认值。连接字段采用
  generation-safe reload；模型、并行数和提醒热更新到后续任务，不中断 active run。配置页内置
  脱敏自检，并保留 `/status`、`/doctor` 深入诊断入口。
- **每会话执行模式（issue #35）**：`quick`、`balanced`、`deep` 以 immutable scope 持久化，
  SDK、ACP 与 Web 共用同一 prompt seam；切换只影响下一任务，不会清空 transcript 或削弱审批门禁。
- **显式 DSH session 投影（issue #53）**：可把 dsh Web session 独占绑定到飞书私聊、群聊或话题，
  支持有界 history、live mux、重启 catch-up、稳定幂等键、echo suppression 与管理员确认迁移。
- **可靠性与协作能力集中升级**：新增持久任务对账、回复流控、会话归档回传、跨会话通知、
  scope 工具权限、聊天内脱敏诊断、多机器人交接、member 隔离、计划审批与双语卡片；全部保持
  rc.8 SDK/ACP/Web 一致性与 fail-closed 安全边界。

**安装 / 升级 · Install & upgrade**：

```bash
npx dsh-lark-bot@latest setup --profile dsh-lark
npx dsh-lark-bot@latest upgrade --profile dsh-lark --yes
```
