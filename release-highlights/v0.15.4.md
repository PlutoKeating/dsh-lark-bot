## Highlights / 本版亮点

- **安全修复（awesome-dsh-plugin PR #1408 审核阻断项）**：`/invite` 的写操作（`user` /
  `admin` / `group` / `remove`）此前缺少 `requireAdmin` 鉴权，任意可私聊 bot 的用户可发送
  `/invite admin <自己的 open_id>` 自我提权，随后解锁 `/key set`（写凭据）、`/provider`、
  `/notify`。本版为写操作补上与 `/role`、`/notify`、`/model`、`/provider`、`/key` 相同的
  管理员守卫（`/invite list` 保持只读开放），并新增自我提权防护测试。
- 首个扫码绑定的 operator 自动成为管理员（原有行为），后续管理员仅能由现有管理员添加。

**安装 / 升级 · Install & upgrade**：

```bash
npx dsh-lark-bot@latest setup --profile dsh-lark
npx dsh-lark-bot@latest upgrade --profile dsh-lark --yes
```
