# v0.19.6 — Reliable in-chat upgrades across npx, Corepack, and pnpm layouts

- Fixes issue #98: the Guardian update worker now validates npm/npx-flat runtime dependencies through Node's real module resolution, re-reads the exact package installed by `dsh plugin add`, and relinks SDK/ACP profiles only to that stable installation instead of a transient npx cache.
- Fixes issue #99: existing dsh profiles preserve the exact pnpm release recorded in `node_modules/.modules.yaml` before installation, preventing source-managed dsh and Corepack from selecting a different store major and failing with `ERR_PNPM_UNEXPECTED_STORE`. Fresh profiles remain owned by dsh initialization.
- Fixes issue #100: SDK dependency validation resolves pnpm package symlinks to their physical `.pnpm` target before module lookup, avoiding false corruption reports and unnecessary forced installs after a successful upgrade.
- Adds regression coverage for npx-flat packages, stable installed-root handoff, exact target verification and rejection, Corepack profile pinning (including full semver metadata), fresh-profile initialization, and pnpm isolated symlink trees.

Upgrade and reload the managed profile:

```bash
npx dsh-lark-bot@latest upgrade --profile dsh-lark --yes --restart
```
