## Highlights / 本版亮点

- **修复自定义 provider 填错完整接口地址导致的 404（issue #47 第四次修复）**：
  dsh 的 pi-ai 适配器会在配置的 `baseURL` 后面自行追加 `/chat/completions` 等操作路径。
  用户按网关文档粘贴完整端点（如 `https://www.kingapi.xyz/v1/chat/completions`）时，
  请求 URL 会变成双写路径，网关返回
  `模型不存在或未开通 / code: not_found`（真实复现：`/v1/chat/completions` 请求 200，
  双写路径请求 404 且报错文案与线上完全一致）。本版 `normalizeBaseUrl()` 现在会自动
  去掉末尾的 `/chat/completions`、`/responses`、`/messages`，deepseek-official 走
  `normalizeDeepseekBaseUrl()`（同样去后缀但保留裸根域名，官方 API 在根路径提供接口）。
- **`/model default` 现在真正“新会话生效”**：此前模型优先级是「scope 覆盖 > profile
  preferences.model > dsh agent-default-model」，当 profile 里残留旧模型偏好时，
  `/model default` 写入了 dsh 配置却仍被 profile 偏好压住。现在 `/model default`
  同时写入 bridge profile 偏好，管理员选的默认模型对所有新会话生效。

**安装 / 升级 · Install & upgrade**：

```bash
npx dsh-lark-bot@latest setup --profile dsh-lark
npx dsh-lark-bot@latest upgrade --profile dsh-lark --yes
```
