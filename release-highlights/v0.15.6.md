## Highlights / 本版亮点

- **修复 pi-ai provider 注册竞态（issue #47 二次修复）**：dsh SDK runtime 启动后需要几百毫秒
  才异步注册 `llm-pi-ai` 的自定义 provider 路由，桥接在模型切换后立即重建 runtime 时会在窗口内
  握手失败，报 `no adapter registered for provider "kingapi"`。本版改为在同一 runtime 子进程内
  轮询重试 initialize 直到路由注册完成（真实 runtime 复现验证：150/300ms 失败、600ms 成功），
  `/model use` 到自定义 provider 后第一轮即生效。
- **命令失败不再被误转发给 agent**：`/providers`、裸 `/provider` 等命令若执行异常，之前会被
  静默当作普通消息发给 agent（表现为莫名其妙的「agent 失败」）。现在直接回复具体错误；交互卡片
  发送失败时自动降级为文字列表。
- **凭据自动关联**：`/key set kingapi <值>` 而 provider 未设 `apiKeyEnv` 时，自动把
  `apiKeyEnv` 关联到同名 provider；已存在的老配置在下次运行时自动补齐，密钥真正生效。

**安装 / 升级 · Install & upgrade**：

```bash
npx dsh-lark-bot@latest setup --profile dsh-lark
npx dsh-lark-bot@latest upgrade --profile dsh-lark --yes
```
