- Accepts inert SDK shell metadata without weakening the plan gate, so approved read-only work no longer stalls on empty or introspection-only `bash` calls (#59).
- Discovers providers, models, input capabilities, and reasoning metadata from the live models.dev catalog instead of embedding fixed provider, model, or effort lists; stale cache data remains available during transient catalog outages (#80).
- Delivers uploaded images to the SDK agent as native durable attachment content blocks, with format detection and explicit safeguards against replacing unreadable images with invented path-based analysis (#81).
- Unifies permission, plan-gate, and file-sandbox denial attribution across the bridge and nested agents, including actionable reason and remediation metadata (#82).
- Includes the scoped SDK runtime and session-isolation correction for the reporter's post-v0.17.0 reproduction (#79), previously shipped in v0.17.1/v0.17.2 and covered by the current regression suite.
