# v0.19.12 — Service PATH sanitization, model fallback, service-install takeover

- Fixes #111 (managed service env): `snapshotServiceEnv` no longer copies `PATH` verbatim from the
  invoking shell into the service env file. `npx dsh-lark-bot@latest service restart` was pinning the
  npx cache bin (`~/.npm/_npx/<hash>/node_modules/.bin`) and cwd-walk `node_modules/.bin` entries (an
  ephemeral plugin version) into the long-lived service — silently, since `doctor` / `service status` /
  `/version` all read the running package manifest. The guardian's existing filter (#102) is extracted
  into a shared `sanitizeServicePath()` and now also applied to the engine env snapshot, with the Node
  bin dir prepended so the service resolves `node`/`pnpm` from a stable location.
- Fixes #112 Bug C: `preferences.model` (the fresh-install default `""`) no longer overrides
  `DSH_LARK_MODEL`. A new `resolveModelChoice()` treats a blank bridge-profile model as unset so the
  env var wins, avoiding an empty `AgentOptions.model` at startup.
- Fixes #112 Bug D: `service install|start|restart` no longer deadlocks when a guardian-spawned dsh
  process is running. Process observation now captures the parent PID (`ps pid=,ppid=,args=` / CIM
  `ParentProcessId`), and the unmanaged-duplicate guard stops a profile process whose parent is the
  resident guardian instead of erroring "please stop it in the original terminal", letting the managed
  service take over.
- Fixes #112 Bug E: the `model-catalog` refresh-failed log is downgraded from `warn` to `info` — a
  `models.dev` refresh timeout on restricted networks is expected and benign (short-TTL cache +
  stale-on-error).
- Bug A (process-card reanchor race) and Bug B (pnpm SDK runtime readiness) were already resolved in
  v0.19.11 / #100; verified only.
- Regression tests: `sanitizeServicePath`, `snapshotServiceEnv` PATH stripping/dedup,
  `resolveModelChoice`, guardian-spawned process takeover, and updated process-watch fixtures.

Verified against the full local suite (147 files / 826 passed), typecheck, build, and the publish-bundle gate.
