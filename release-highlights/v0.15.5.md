## Highlights / 本版亮点

- **Provider / 模型 / 凭据热重载修复（issue #47）**：此前 `/model use <id>` 只更新了显示，
  dsh runtime 仍用初始化时的 provider/model 路由（SDK JSON-RPC 协议在 session 创建时绑定
  route），导致新增 pi-ai provider 后出现 `pi-ai provider "kingapi" has no configured model
  "deepseek-v4-flash"`。本版在每轮运行前把模型解析为「provider + model」并传给 runtime，
  SDK 适配器在路由变化时自动重建（并行中的旧任务以 retire-drain 方式安全收尾，不会被打断）；
  `/model default` 按 dsh 官方 schema 写入 `{ provider, model }`；pi-ai Base URL 根域名自动
  补全 `/v1`。
- **BotFather 式交互管理卡片（issue #16 / #47）**：`/providers` 与裸 `/provider` `/model`
  `/key` 打开管理卡片；新增 9 条多轮向导（添加/修改/删除 provider，增删/切换/默认模型，
  设置/删除凭据）——选择用按钮、填值用卡片输入、写入前确认、随时取消，写操作仅管理员。
  原文字命令全部保留。
- **凭据关联引导**：`/key set <引用名> <值>` 只写凭据文件；provider 需在 `apiKeyEnv` 引用
  同一名字才能生效，本版在命令回复与文档中显式提示这一关联关系。

**安装 / 升级 · Install & upgrade**：

```bash
npx dsh-lark-bot@latest setup --profile dsh-lark
npx dsh-lark-bot@latest upgrade --profile dsh-lark --yes
```
