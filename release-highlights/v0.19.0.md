# v0.19.0 — Feishu/Lark self-update

- Adds an administrator-only `/upgrade` flow that checks the official npm registry and presents a bilingual confirm/cancel card when a newer version is available.
- Hands confirmed upgrades to Guardian using an exact package version, durable state, runtime repair, validation, minimal service reload, and one-time result delivery back to the originating conversation.
- Checks for an available npm update after every `/new` or `/reset` and sends only a short ordinary text reminder when one exists.
- Preserves sessions, archives, configuration, and credentials across reloads, while clearly warning that active tasks are interrupted.
- Hardens concurrent update handling, restart reconciliation, result delivery, administrator authorization, and failure reporting without exposing child-process output.
