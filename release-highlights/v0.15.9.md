## Highlights / 本版亮点

- **审批卡和问答卡提交后终于有明确反馈（issue #48）**：业务结果先完成结算，飞书客户端立即
  显示成功 toast；随后在原消息或话题中发送终态确认并撤回旧卡片。确认消息与撤回是互相隔离的
  best-effort 收尾，任一网络请求失败都不会影响 agent 已收到的审批结果或答案。
- **PersonalAgent 群聊可选择免 @ 触发（issue #50）**：设置
  `DSH_LARK_GROUP_NO_AT=true` 后，bridge 会对已登记群聊/话题增量读取历史 API，并复用实时消息
  管线。实现包含 per-chat 水位、跨事件/轮询 message ID 去重、完整分页、白名单及
  stale/deleted/system/bot 过滤；默认关闭且不回放启动前消息。`doctor` 可探测
  `im:message.group_msg` 权限，README 与 Quick Start 已说明隐私边界和开启步骤。

**安装 / 升级 · Install & upgrade**：

```bash
npx dsh-lark-bot@latest setup --profile dsh-lark
npx dsh-lark-bot@latest upgrade --profile dsh-lark --yes
```
