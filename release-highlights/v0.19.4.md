# v0.19.4 — Hermetic tests, channel skill, and a process card that follows the conversation

- Completes issue #91: the hermetic test harness now fully isolates the ambient `DSH_HOME` so tests can never clobber the repository's own `package.json` (regression covered by `test/test-hermeticity.test.ts` and the guarded `test/setup.ts`).
- Fixes issue #92: the `dsh-lark-bot` channel skill is now exposed on the agent runtime overlay (`src/skill/index.ts`), so agents can actually load and follow the channel skill for setup, configuration, and diagnostics.
- Adds issue #93: the in-progress run card is re-anchored to the tail of the conversation whenever a new user-facing bubble is delivered, so you no longer have to scroll up to confirm a task is still running (`src/bridge/run-card-anchors.ts` + `attachRunCardAnchors`).
- Adds issue #94: the collapsible execution panel now defaults to collapsed, keeping the per-run process card compact.

Upgrade and reload the managed profile:

```bash
npx dsh-lark-bot@latest upgrade --profile dsh-lark --yes --restart
```
