# v0.19.3 — Trustworthy guardian diagnostics and resilient in-chat upgrades

- Completes issue #75: `guardian status` now reports the verified resident guardian PID across Linux, macOS, and Windows, remains stable across successive queries, and fails closed on ambiguous or stale identities instead of reporting the query process.
- Fixes issue #90 from a real Feishu `/upgrade` failure: the Guardian worker now uses a clean neutral working directory, a per-request isolated npm cache, and an explicit private child umask, so a damaged global npm cache or package-source cwd cannot break self-update.
- Replaces opaque update exit codes with bounded, redacted failure categories and actionable bilingual guidance without persisting or sending raw worker output.
- Adds focused cross-platform PID tests, hostile-umask/cache/cwd regressions, and an opt-in live channel-upgrade E2E that exercises npm bootstrap, Guardian reinstall, doctor verification, and managed-profile reload.

Upgrade and reload the managed profile:

```bash
npx dsh-lark-bot@latest upgrade --profile dsh-lark --yes --restart
```
