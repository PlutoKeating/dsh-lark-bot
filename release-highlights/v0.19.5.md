# v0.19.5 — Interim text bubbles, vision model image input, and a reliable running version

- Adds issue #95: the agent's streaming text is now emitted as **independent Feishu message bubbles** during a run instead of being merged into one final message at completion. Each logical message (a text segment before a tool call / thinking, or a pause in the stream) is delivered in real time and the process card follows it to the tail of the conversation (`src/bridge/run-flow.ts`, `INTERIM_BUBBLE_PAUSE_MS`).
- Fixes issue #96: vision-capable models such as `deepseek-v4-flash-vision-exp` now default to `inputModalities: ['text','image']` on registration and selection, so an image sent to a vision model is no longer rejected with *"does not accept image input"* (`src/config/dsh-config.ts`).
- Fixes issue #97: the running version is now resolved from the package's own manifest (same source as `--version`) instead of an upward filesystem walk that could match a stale copy, so `/new` and `/upgrade` no longer disagree (e.g. a bogus `0.9.0` vs `0.19.3`) (`src/adapters/dsh/own-package.ts`, `src/upgrade/update-check.ts`).

Upgrade and reload the managed profile:

```bash
npx dsh-lark-bot@latest upgrade --profile dsh-lark --yes --restart
```
