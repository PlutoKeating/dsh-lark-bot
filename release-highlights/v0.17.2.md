# v0.17.2 — Scoped SDK runtime isolation

- Isolates SDK runtime cancellation by scope/workspace and by concurrent session, so a task-card stop or `/stop` in one group never terminates another group's work.
- Reuses native SDK session IDs only while the current bridge process still owns the exact idle runtime; restart, stop, concurrent runs, and model-route changes now start fresh with bridge transcript replay instead of triggering rc.8 persisted-log collisions.
- Keeps the existing neutral collision recovery as a last-resort fallback and documents the trusted-profile `DSH_LARK_PLAN_GATE=off` option introduced in v0.17.0.
- Makes the portable-supervisor shutdown test wait for its child to spawn, eliminating a CI scheduling race that blocked the first v0.17.1 release attempt before any package was published.
